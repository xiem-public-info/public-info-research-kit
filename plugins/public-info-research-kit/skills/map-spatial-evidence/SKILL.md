# 地图与空间证据

空间事实和客户面显示必须分别验收。

1. 先核项目锚点、POI 身份、几何类型、坐标口径、距离方法和比较范围。
2. 逐项核对项目锚点、POI 身份、几何类型、坐标口径和距离方法；代理点、直线距离和路线距离不得混写。
3. 底图采用 OpenStreetMap Standard 标准地图层，不称为卫星影像。
4. 只允许当次人工打开、有限视窗的截图或局部装配；不得批量下载、预取或制作离线瓦片包。
5. 用 `tools/assemble_osm_asset.py` 装配本地截图时，必须保留清晰可见的 `© OpenStreetMap contributors` 署名。项目水印可另加，但不得遮挡或替代该署名。
6. 客户面状态还要求范围清楚、标签可读、碰撞已检查且空间事实已经通过；显示好看不能替代事实核验。

若任一层未通过，只交付内部候选图、缺口或待核项，不写成客户面地图已就绪。

## 使用边界（0.5.0）

- 使用本人的正常账号和本机正常界面，保持合理频率；完整保留当前可见桌面研究能力。
- 不迁移、上传或交接 Cookie、token、profile、扫码凭证、本地存储、私聊、通讯录或非公开资料。
- 不绕过登录、验证码、付费墙、权限墙、风控或访问控制；出现安全确认时交由本人处理后继续。
- 依赖鼠标、键盘、窗口焦点或剪贴板的任务在同一台 Mac 上串行执行；这只是桌面冲突控制，不是授权机制。
- 引用第三方文字、图片、音视频或地图时保留必要来源与署名；OSM 图件保留可见 `© OpenStreetMap contributors`。
