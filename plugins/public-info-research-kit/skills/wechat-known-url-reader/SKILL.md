# 微信具名链接阅读

本 Skill 只处理用户直接提供的已知文章 URL，不把链接任务改写成微信关键词搜索。

1. 校验请求包含任务编号、业务问题、已知 URL、使用边界和停止条件。
2. 第一优先使用 Codex 内置浏览器直接打开和阅读。
3. 记录请求 URL、实际浏览器表面、打开结果，以及标题—正文—日期映射和阅读覆盖。
4. 只有内置浏览器出现明确技术故障且任务仍需继续时，才可使用普通外部浏览器，并记录回退原因。
5. 登录墙、权限墙、验证码或不可读页面返回 `gap`；不得绕过。

具名链接模式与精确查询模式使用不同请求结构。不得要求查询垫板，也不得把打开链接写成已完成微信搜索。

## 使用边界（0.4.0）

- 使用本人的正常账号和本机正常界面，保持合理频率；完整保留当前可见桌面研究能力。
- 不迁移、上传或交接 Cookie、token、profile、扫码凭证、本地存储、私聊、通讯录或非公开资料。
- 不绕过登录、验证码、付费墙、权限墙、风控或访问控制；出现安全确认时交由本人处理后继续。
- 依赖鼠标、键盘、窗口焦点或剪贴板的任务在同一台 Mac 上串行执行；这只是桌面冲突控制，不是授权机制。
- 引用第三方文字、图片、音视频或地图时保留必要来源与署名；OSM 图件保留可见 `© OpenStreetMap contributors`。
