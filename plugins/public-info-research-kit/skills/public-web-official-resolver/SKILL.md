# 公开网页与官方文档

1. 优先确认来源身份、发布主体、发布日期和稳定 URL。
2. 公开 HTML 直接阅读并保留页面标题、正文范围、表格或附件指针。
3. PDF 先运行 `python tools/triage_official_document.py` 判定原生文本、扫描或混合类型，再决定是否需要 OCR。
4. OCR 只处理完成任务所需页面；默认使用本机可选提供方，不上传文档，不把 OCR 文本写成已人工确认事实。
5. 遇到登录、授权、付费或访问限制时返回 `gap`，不借用微信或小红书执行器，也不绕过限制。
6. 网络访问必须由当前任务明确需要；离线 doctor 和 fixture 不得联网。

输出应保留来源角色、原始声明、时间、冲突和使用边界。搜索结果摘要只能作为发现入口，不能替代原页。

## 使用边界（0.5.0）

- 使用本人的正常账号和本机正常界面，保持合理频率；完整保留当前可见桌面研究能力。
- 不迁移、上传或交接 Cookie、token、profile、扫码凭证、本地存储、私聊、通讯录或非公开资料。
- 不绕过登录、验证码、付费墙、权限墙、风控或访问控制；出现安全确认时交由本人处理后继续。
- 依赖鼠标、键盘、窗口焦点或剪贴板的任务在同一台 Mac 上串行执行；这只是桌面冲突控制，不是授权机制。
- 引用第三方文字、图片、音视频或地图时保留必要来源与署名；OSM 图件保留可见 `© OpenStreetMap contributors`。
