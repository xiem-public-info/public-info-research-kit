# 建筑素材的身份、视角与使用边界

只在原任务要求建筑形态素材时采用；普通坐标、距离任务仍按空间证据v2执行，不自动扩大。

- 先固定对象编号，贯穿总览、单体、文件与说明。名称修正不换编号，新增续号，取消保留标记。按道路、屋顶、外形及邻近地标核对身份，不仅凭中心点把编号投到斜俯照片。
- 真实形态、空间关系、生成参考分开。主体模糊、太小或遮挡的关系图不计立面覆盖；同机位裁切或转载不增加独立视角。生成图不回填真实证据。
- 按对象和视角缺口选择正常可用来源，不把某一全景平台设为唯一来源。保留原图、来源、时间、支持的构件及缺口；效果图与建成照片分开。
- 原任务需要航拍导航时，用实际核读的真实航拍作独立标注层，固定号与单体对应；目标框不表示项目红线。不用地图或生成鸟瞰冒充真实航拍。
- 基本色双方向斜视仅按原任务允许的图像生成能力制作并核对形态。用户只要真实素材时省略；本包没有新增图像生成或建模执行器。
- Blender／GLB／UE制作和采用只按明确请求另行安排，不因存在素材自动启动。比例参考不升级为精确尺度，素材覆盖、建模采用及客户验收分别报告。
