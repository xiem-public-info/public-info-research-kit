# 共享桌面与提交前输入核对

依赖同一台电脑的鼠标、键盘、焦点、剪贴板、可见窗口或截图的任务共享一个排他GUI执行权，不按微信、小红书、地图分别放行。HTTP、API及不依赖前台的文件处理可以并行。只在输入、提交、阅读或恢复动作完整结束且可恢复的检查点释放；超时不自动抢占，恢复前重新确认原持有任务及当前页面归属。

下游决定业务问题、对象、用途、完成要求、明确排除和停止条件；研究包按任务授权安排渠道、精确查询词、配额和迭代。用户明确指定的词和范围保持。

普通网页／地图的GUI操作先填入，再取得新鲜可见画面核对目标页面、输入框和精确文本，确认一致后才单次提交。不得将未核对的填入与回车合成连续动作。文本不一致、界面变动或页面归属不明时立即停止提交，按渠道规则诊断恢复；工具调用成功不能代替可见核对。

微信、小红书各自的现行输入及停止规则优先。本说明不授权控件树、剪贴板、浏览器接管或渠道已禁止的替代方式，不建立新恢复状态机。这里是操作约束，不证明工具内部故障已修复、全局租约或运行时互斥已实现。
